# Antigravity 生圖提示詞指南（Image Prompt Guidance）

本技能的所有投影片視覺資產，必須優先透過 Antigravity 原生生圖工具（`generate_image`）或 `antigravity-draw` 雙軌路線生成，嚴禁使用程式碼幾何繪圖取代。

---

## 提示詞結構（Prompt Structure）

撰寫每頁生圖提示詞時，請包含以下 5 個維度：

1. **版型佈局（Layout Hint）**：指定視覺重心（如「左側 45% 留深色乾淨空白區供文字疊加，右側 55% 為主視覺插畫」或「中央對稱大視覺」）。
2. **圖像核心內容（Subject & Action）**：具體的人事物、動作、情緒、場景細節。
3. **畫面文字（Text on Image）**：
   - `baked` 模式：明確寫出需要呈現的繁體中文主標題或短金句（保持在 20 字以內）。
   - `plate` 模式：**明確註明「畫面完全不要有任何文字、英文字母、標籤或水印」**。
4. **共享風格規範（Style Tokens）**：
   - 比例：`16:9 橫版簡報`（呼叫 `generate_image` 時設定 `AspectRatio: '16:9'`）。
   - 風格：現代扁平向量插畫 / 暖色手繪繪本 / 3D 擬真渲染 / 賽博極簡等。
   - 色彩：深夜藍 `#0D1B2A`、科技青 `#00C6FF`、金黃點綴 `#FFD700` 等。
5. **負向約束（Negative Prompt / Avoid）**：
   - 避免模糊照片、雜亂背景、亂碼、多餘文字、噪點、低解析度。

---

## 模式範例

### 1. Baked 烘焙模式（圖文一體）

```text
16:9 橫版簡報。
版面構圖：左側為醒目文字區，右側為動態插圖。
圖像內容：一位親切自信的小學數學老師站在發光的智慧黑板前，黑板上漂浮著立體幾何圖形與清晰比例尺。
畫面文字：上方標題「看見比例」，下方副標「生活中的數學之美」。繁體中文，字體俐落大氣。
風格：現代扁平向量插畫風，科技感微漸層，深夜藍深底，亮青藍主色，金黃點綴。
約束：不要雜亂文字、不要英文亂碼、不要逼真寫實照片、畫面乾淨。
```

### 2. Plate 底圖疊字模式（無字底圖）

```text
16:9 橫版簡報視覺底圖。
版面構圖：左側 50% 保持深藍色乾淨暗部留白空間（供 PowerPoint 疊加文字），右側 50% 放置主視覺元素。
圖像內容：一座通往未來的數位圖書館，發光的書籍與資料流螺旋上升，充滿探索感。
風格：現代 3D 渲染，深色調背景（#0D1B2A），青藍光影與金黃微光粒子。
絕對約束：整張圖片中「完全不要出現任何文字、英文字母、符號、浮水印或商標」，留白區必須平整乾淨。
```

---

## 建議設定

- **長寬比**：呼叫 `generate_image` 時指定 `AspectRatio: '16:9'`。
- **命名規範**：`page_01`, `page_02`, `page_03`... 便於打包腳本排序。
- **儲存路徑**：生成後由 Agent 將產物儲存至專案目錄 `slides/images/page_01.png` 等。
